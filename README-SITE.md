# Mise en ligne — Anime Organizer

1. Appliquer la V4 dans Termux, une fois la V3 terminee. Le script pousse sur main et GitHub Actions lance les compilations.
2. Une fois les jobs Android, Windows et Publier les telechargements verts, une release est publiee automatiquement.
3. Dans le depot GitHub : **Settings → Pages → Build and deployment → Deploy from a branch → main → /docs → Save**.
4. Adresse attendue une fois Pages active : https://janintibo-art.github.io/anime-organizer/
5. Le site propose les liens `/releases/latest/download/` vers l'APK, le setup Windows et l'archive Windows portable. Avant la premiere release, les liens peuvent renvoyer une erreur 404.
6. Pour les images panoramiques, renseigner une cle API TMDB dans les reglages existants de l'application. Sinon, l'affiche d'origine continue de servir de fond.

Le site distribue uniquement le logiciel, pas de videos, episodes, affiches ou extraits d'anime sous droits. Une page de captures du logiciel peut etre ajoutee avec des exemples generiques ou captures dont la diffusion est autorisee.
